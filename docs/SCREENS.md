# صفحات اصلی اپ

1. **خانه / داشبورد**
   - وضعیت فعلی (تعداد آیتم‌های Inbox، موضوعات فعال یادگیری)
   - دکمه سریع تخلیه ذهن
   - دسترسی سریع به جلسه یادگیری

2. **صندوق ورودی (Mind Dump)**
   - لیست آیتم‌های پردازش‌نشده
   - دکمه اضافه کردن سریع
   - امکان پردازش و انتقال به دسته‌های دیگر

3. **یادگیری فعال**
   - لیست حداکثر ۲ موضوع فعال
   - ورود به جریان چرا → توضیح → پروژه → جمع‌بندی
   - تایمر جلسه

4. **دانش و ایده‌ها**
   - لیست دانش تثبیت‌شده
   - جستجوی ساده

5. **بعداً (Curiosity)**
   - موضوعاتی که کنجکاو هستی اما الان وقتش نیست

6. **مرور**
   - جمع‌بندی روزانه خیلی کوتاه
   - مرور هفتگی
