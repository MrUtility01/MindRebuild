# ویژگی‌های اضافی تأیید شده

## جملات انگیزشی
- ترکیبی از جملات مذهبی و جملات جهانی
- نمایش در صفحه خانه
- قابلیت چرخش جملات

## گزارشات
- صفحه جداگانه گزارشات
- نمایش خلاصه و لیست بخش‌های مختلف:
  - موضوعات ذهن (صندوق ورودی)
  - یادگیری
  - کارها
  - خاطرات
  - دانش
  - کنجکاوی‌ها

## بک‌آپ و اکسپورت
- امکان تهیه بک‌آپ محلی
- امکان خروجی گرفتن (حداقل Markdown یا فایل متنی)
- کاملاً آفلاین

## صفحه آموزش برنامه
- خیلی کامل و جامع
- در مرحله آخر توسعه ساخته می‌شود
- شامل توضیح تمام بخش‌ها و نحوه استفاده مطابق سبک یادگیری کاربر

## پردازش انعطاف‌پذیر
- کاربر می‌تواند فقط تخلیه کند
- یا بنویسد و بعداً پردازش و مرتب‌سازی کند
