# راهنمای کامل ساخت اپ از صفر تا صد

این سند توضیح می‌دهد چطور این اپ از صفر ساخته می‌شود و با گیت‌هاب چطور کار می‌کنیم.

## مرحله ۱: آماده‌سازی محیط

1. نصب Android Studio (آخرین نسخه پایدار)
2. نصب JDK مناسب
3. ساخت حساب گیت‌هاب (انجام شده: MrUtility01)
4. نصب Git روی سیستم

## مرحله ۲: ساخت پروژه اولیه

- ایجاد پروژه جدید با Jetpack Compose
- انتخاب Minimum SDK مناسب (پیشنهاد: API 26 یا بالاتر)
- فعال‌سازی RTL و پشتیبانی از فارسی

## مرحله ۳: ساختار پوشه‌ها (پیشنهادی)

```
app/
  src/main/java/com/mindrebuild/
    data/           # مدل‌ها و Room
    domain/         # منطق کسب‌وکار
    ui/             # صفحات و کامپوننت‌ها
      home/
      inbox/
      learning/
      tasks/
      journal/
      guide/
    util/           # تاریخ شمسی و ابزارها
```

## مرحله ۴: پیاده‌سازی به ترتیب اولویت

1. مدل داده + Room
2. صندوق ورودی (Mind Dump)
3. جریان یادگیری مرحله‌ای
4. تایمر جلسه
5. کارها با تاریخ شمسی
6. دفتر خاطرات
7. راهنما و تکنیک‌ها
8. برنامه‌ریزی روزانه
9. صفحه مستندات ساخت

## مرحله ۵: کار با گیت‌هاب

- هر ویژگی مهم در یک branch جدا
- Commitهای کوچک و معنادار
- Push منظم
- استفاده از Issues برای پیگیری کارها

## مرحله ۶: تست و آماده‌سازی نهایی

- تست روی دستگاه واقعی
- بررسی RTL و تاریخ شمسی
- ساخت APK نهایی

## نکات مهم

- همیشه اول سادگی را حفظ کن
- هر ویژگی جدید باید با سبک یادگیری کاربر سازگار باشد
- مستندات را همزمان با کد به‌روز نگه دار
