# MindRebuild

**اپلیکیشن اندروید شخصی‌سازی‌شده برای سامان‌دهی ذهن، یادگیری مفهومی و شروع از صفر**

این پروژه بر اساس سبک یادگیری مفهومی-منطقی کاربر طراحی شده و شامل تمام بخش‌های مورد نیاز برای خالی کردن ذهن، یادگیری عمیق، مدیریت کارها، برنامه‌ریزی روزانه و دفتر خاطرات است.

## ویژگی‌های نسخه اول (کامل)

- کاملاً آفلاین
- فارسی و راست‌چین
- پشتیبانی از تاریخ و ساعت شمسی
- ظاهر کمی مدرن
- جریان یادگیری مرحله‌ای و اجباری

### بخش‌های اصلی

1. **خانه / امروز**
2. **تخلیه ذهن** + تکنیک‌های کاهش استرس و اضطراب
3. **یادگیری** (جریان چرا → توضیح → پروژه → جمع‌بندی + لیست موضوعات آینده)
4. **راهنمای سبک یادگیری** (صفحات ثابت + مسیر مرحله‌به‌مرحله)
5. **تکنیک‌های یادگیری بهتر**
6. **مدیریت کارها** (با تاریخ و ساعت شمسی)
7. **برنامه‌ریزی روزانه**
8. **دفتر خاطرات**
9. **دانش و آرشیو**
10. **مستندات ساخت اپ** (از صفر تا صد + کار با گیت‌هاب)

## فلسفه طراحی

- فهم «چرا» قبل از هر چیز
- جلسات کوتاه و متمرکز
- اتصال یادگیری به کار واقعی
- مدیریت کنجکاوی
- سادگی در عین کامل بودن
- آفلاین و تحت کنترل کاربر

## وضعیت پروژه

مشخصات کامل محصول نهایی شده است. در حال آماده‌سازی ساختار پروژه اندروید و مستندات توسعه.
