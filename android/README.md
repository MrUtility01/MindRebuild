# MindRebuild Android App

این پوشه شامل کد منبع اپلیکیشن اندروید است.

## ساختار پروژه

```
android/
├── app/
│   └── src/main/
│       ├── java/com/mindrebuild/
│       │   ├── data/          # مدل‌ها و Room
│       │   ├── domain/        # منطق کسب‌وکار
│       │   ├── ui/            # صفحات Compose
│       │   └── util/          # ابزارها (تاریخ شمسی و ...)
│       └── res/
└── docs/
```

## وضعیت فعلی

- مدل‌های داده اولیه آماده شده
- ساختار پوشه‌ها ایجاد شده
- صفحه خانه و صندوق ورودی در حال پیاده‌سازی
